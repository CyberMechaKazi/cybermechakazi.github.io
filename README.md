# Kazi Islam - Personal Portfolio

A responsive personal website designed for job applications and employer review.

## Included sections

- Professional introduction and bio
- Technical skills
- Work and research experience
- Featured GitHub projects
- Education
- Contact information

## Preview locally

Open `index.html` in a browser. For the most reliable preview, run a small local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files and folders from this project.
3. Open the repository's **Settings**, then **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will provide the public website address after deployment.

## Update later

- Replace the text in `index.html` to update the bio, experience, or projects.
- Update the GitHub and LinkedIn links in `index.html` when needed.
